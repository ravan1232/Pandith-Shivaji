## 🚀 Running Locally

To run the application locally on your computer:

```bash
# Clone the repository
git clone https://github.com/ravan1232/Pandith-Shivaji.git

# Navigate into the project folder
cd Pandith-Shivaji

# Run using npm
npm run dev

# Or run using any static file server
npx serve .
# or Python
python -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
